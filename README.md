**Framie** is a **mobile-first Progressive Web App (PWA)** designed to be used like a real phone app .. especially with your camera.

**Important Note:** Framie is *not* meant to be used as a normal desktop website.

---
────୨ৎ────
## ⊹ ࣪ ˖ What is Framie? ⊹ ࣪ ˖
Framie is a PWA that lets you:
- Use your phone camera
- Overlay inspiration photos
- Save images locally using IndexedDB
- Navigate between camera, albums, and inspiration groups
- Use it offline once "installed"

It’s built to feel like a native mobile app!!  not a traditional website.

## How to Use Framie (Recommended)  ₍ᐢ. .ᐢ₎ ₊˚⊹♡
────୨ৎ────
### On Your Phone (Best Experience)

1. Open the app link in **Safari (iOS)** or **Chrome (Android)**
2. Tap **“Add to Home Screen”**
3. Launch Framie **from your home screen**

This enables:
- Fullscreen experience
- Camera access
- Proper layout & gestures
- App-like behavior (no browser UI)

> Framie works best when installed as a PWA — just like a real app.

---
────୨ৎ────
## Using Framie on Desktop (For Development / Preview Only)

Framie is **mobile-only by design**, but if you *must* view it on desktop:

1. Open the site in Chrome
2. Right-click → **Inspect**
3. Toggle **Device Toolbar** (📱 icon)
4. Select an **iPhone model** (recommended)
5. Refresh the page

Desktop mode without emulation will look broken or incomplete — this is expected.

## Why It Works This Way
- Framie relies on **mobile camera APIs**
- UI is optimized for **touch & portrait layout**
- Data is stored **locally on the device**
- Desktop browsers don’t reflect real usage

This is intentional :3
